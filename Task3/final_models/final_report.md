## 2. Описание трёх финальных MPU-индексов

### 2.1 MPU_rv_std

#### Идея
Простейший бенчмарк: насколько активно ЦБ менял ставку за последние
3 месяца. Основан на инерции волатильности — высокая турбулентность
сегодня предсказывает высокую завтра.

#### Метод построения
$$RV_t = \text{std}(\Delta r_{t-2},\ \Delta r_{t-1},\ \Delta r_t),
\quad \Delta r_t = r_t - r_{t-1}$$

Нормировка: z-score. Данные: только ряд ключевой ставки ЦБ РФ.

#### Метод тестирования
OOS регрессия: $Y(t+h) = \alpha + \beta \cdot MPU(t) + \varepsilon$.
Split 60/40. Критерий: $R^2_{oos} = 1 - MSE_{model}/MSE_{benchmark}$.

#### Результаты

| h | RV R²_oos | Инфляция R²_oos |
|---|---|---|
| 1M | **+0.758** ✅ | −0.996 ✗ |
| 2M | **+0.491** ✅ | −0.857 ✗ |
| 3M | +0.197 ✅ | −0.573 ✗ |
| 6M | −0.144 ✗ | +0.059 ✅ |
| 12M | −0.293 ✗ | −0.350 ✗ |

#### Интерпретация
Лучший предиктор RV на h=1–2M, но это автокорреляция, а не
прогнозная сила. На h≥6M работает mean-reversion и индекс вредит
прогнозу. Для инфляции практически не работает.

---

### 2.2 MPU_decay

#### Идея
Ширина риск-нейтрального распределения (RND) — прямая мера
неопределённости рынка относительно будущей ставки. Агрегация
IQR = Q90 − Q10 по нескольким срокам через убывающие веса:
краткосрочные опционы чувствительнее к ближайшим решениям ЦБ.

#### Метод построения
1. RND методом Breeden-Litzenberger (нормальная модель Башелье).
2. Форвард F = страйк с минимальной IV (ATM-point).
3. $IQR_{9010} = Q_{90} - Q_{10}$ для каждой даты и срока.
4. Агрегация по срокам 1M, 3M, 6M, 1Y:

$$MPU\_decay_t = \sum_{i} w_i \cdot IQR_{9010}(t,\ mat_i),
\quad w_i = \frac{e^{-\ln 2 \cdot i}}{\sum e^{-\ln 2 \cdot j}}$$

Веса: 1M=0.533, 3M=0.267, 6M=0.133, 1Y=0.067.

#### Метод тестирования
OOS регрессия, горизонты h=1,2,3,6,12M.

#### Результаты

| h | RV R²_oos | Инфляция R²_oos |
|---|---|---|
| 1M | −1.782 ✗ | +0.110 ✅ |
| 2M | +0.151 ✅ | **+0.638** ✅ |
| 3M | **+0.328** ✅ | **+0.610** ✅ |
| 6M | +0.364 ✅ | −1.683 ✗ |
| 12M | +0.317 ✅ | +0.102 ✅ |

Среднее R²_oos (h=2,3,6) для RV = **+0.281** — лучший рыночный индекс.

#### Интерпретация
Единственный индекс, устойчиво работающий **и для RV, и для
инфляции**. R²_oos=0.638 при прогнозировании инфляции на h=2M —
исключительный результат. Опережающий характер: широкий IQR сегодня
→ активные решения ЦБ и рост инфляционных ожиданий через 2–3 месяца.

### 2.3 MPU_atm

#### Идея
ATM вменённая волатильность — прямая рыночная цена неопределённости
без необходимости восстанавливать полное распределение. Отвечает на
вопрос задания: «нужно ли вообще считать RND?»

#### Метод построения
1. ATM IV = значение улыбки при форварде (минимум IV) для каждой
   даты и срока (1M, 3M, 6M, 1Y).
2. PCA по матрице ATM IV → первая главная компонента = MPU_atm.

PC1 объясняет **88.3%** дисперсии — максимум среди всех индексов.

#### Метод тестирования
OOS регрессия, горизонты h=1,2,3,6,12M.

#### Результаты

| h | RV R²_oos | Инфляция R²_oos |
|---|---|---|
| 1M | −0.994 ✗ | −5.478 ✗ |
| 2M | −0.112 ✗ | −3.828 ✗ |
| 3M | +0.271 ✅ | −2.583 ✗ |
| 6M | **+0.491** ✅ | −0.033 ✗ |
| 12M | +0.400 ✅ | −0.548 ✗ |

Среднее R²_oos (h=2,3,6) = **+0.217** — второе место для RV.

#### Интерпретация
Лучший индекс для **долгосрочного прогноза RV** (h=6–12M). ATM IV —
медленно меняющийся показатель структурной неопределённости. Для
инфляции не работает из-за переобучения (ATM IV коррелирует с
уровнем ставок, а не с инфляционным каналом).

## 3. Сравнение с альтернативными MPU

В ходе исследования протестировано **10 индексов**. Сравнение по
среднему R²_oos (h=2,3,6):

| Ранг | Индекс | R²_oos | Метод | Статус |
|---|---|---|---|---|
| 1 | **MPU_decay** | +0.281 | RND + decay-веса | ✅ Финальный |
| 2 | **MPU_atm** | +0.217 | ATM IV + PCA | ✅ Финальный |
| 3 | MPU_pca | +0.205 | RND + PCA | Близок к decay (r=0.994) |
| 4 | MPU_rwd | +0.160 | RWD + PCA | Слабее из-за λ-неопределённости |
| 5 | **MPU_rv_std** | +0.063 | RV ставки | ✅ Финальный (только h=1–2M) |
| 6 | MPU_rv_har | +0.050 | HAR-RV | Слабый бенчмарк |
| 7 | MPU_ext | −0.061 | IQR+ΔIQR+Tail | Нестабилен (ΔIQR зашумлён) |
| 8 | MPU_bf | −0.886 | Butterfly IV | Хвосты ≠ амплитуда |
| 9 | MPU_vrp | −3.605 | Var(RND)−Var(RWD) | Нестабилен при малой выборке |
| 10 | MPU_rr | −4.194 | Risk Reversal | Направление ≠ амплитуда |

**Ключевой методологический вывод:**
> Для h≤3M — MPU_decay (RND) лучше.
> Для h≥6M — MPU_atm (без RND) достаточно.
> Оба подхода взаимодополняют друг друга.

## 4. Интерпретация результатов прогнозирования

### 4.1 Прогноз реализованной волатильности

```
MPU_rv_std:  h=1M (+0.758) → h=2M (+0.491) → h=3M (+0.197) → h=6M (−0.144)
MPU_decay:   h=1M (−1.782) → h=2M (+0.151) → h=3M (+0.328) → h=6M (+0.364)
MPU_atm:     h=1M (−0.994) → h=2M (−0.112) → h=3M (+0.271) → h=6M (+0.491)
```

**Что работает и почему:**

На h=1–2M побеждает инерция (MPU_rv_std). Волатильность ставки
автокоррелирована: серии активных решений ЦБ продолжаются несколько
месяцев подряд.

На h=3M лучший рыночный сигнал — MPU_decay. Рыночная неопределённость
(IQR из опционов) содержит информацию о будущих решениях, которую
прошлая RV не захватывает.

На h=6–12M доминирует MPU_atm. ATM IV — медленно меняющийся
индикатор структурного режима ДКП (цикл ужесточения vs смягчения).

**Главное ограничение:** все индексы провалились в rolling OOS из-за
структурного разрыва февраля 2022 (+11.5 п.п. за один месяц). Ни
один рыночный индикатор не способен предсказать геополитический шок
такого масштаба. Фиксированный split 60/40 (IS включает 2022)
даёт более реалистичную оценку прогнозной силы.

### 4.2 Прогноз инфляции

```
MPU_decay:   h=1M (+0.110) → h=2M (+0.638) → h=3M (+0.610) → h=6M (−1.683)
MPU_atm:     все горизонты отрицательные
MPU_rv_std:  все горизонты отрицательные (кроме h=6M: +0.059)
```

**Почему MPU_decay работает для инфляции:**

Механизм передачи через канал ожиданий:
1. Рост IQR (MPU_decay) → рынок ожидает бо́льшую неопределённость
   в ДКП → компании и домохозяйства закладывают риск в цены
2. Результат: инфляция растёт через 2–3 месяца

Это прямое отражение трансмиссионного механизма ДКП через
ожидания — одного из ключевых каналов монетарной трансмиссии.

**Почему провал на h=6M:** ЦБ реагирует на рост неопределённости
повышением ставки → инфляция начинает снижаться через 2–3 квартала.
Сигнал MPU_decay инвертируется на этом горизонте.

**Важная оговорка:** beta с контролями (лаговая инфляция + КС)
оказалась нестабильной из-за мультиколлинеарности при N≈45 IS.
Базовая спецификация предпочтительнее.

## 5. Анализ взаимосвязи с КС и рекомендации по ДКП

### 5.1 Историческая динамика

| Период | КС | MPU_decay | MPU_atm | Характеристика |
|---|---|---|---|---|
| 2019 | 7.75→6.25% | Низкий | Низкий | Плановое снижение, предсказуемый ЦБ |
| 2020 | 6.25→4.25% | Умеренный | Умеренный | COVID-шок, быстрое смягчение |
| 2021 | 4.25→8.5% | Растёт | Растёт | Цикл ужесточения, нарастание неопределённости |
| Фев. 2022 | 8.5→20% | Пик | Пик | Экстренный шок — максимальная неопределённость |
| 2022 (апр–сен) | 20→7.5% | Снижается | Снижается | Быстрая нормализация |
| 2023–2024 | 7.5→21% | Высокий | Высокий | Новый цикл — рынок не знает потолка |
| 2025–2026 | 21→15% | Снижается | Снижается | Начало смягчения, неопределённость падает |

**Событийный анализ** подтвердил: MPU_decay и MPU_atm пикируют в
момент решений ЦБ (t=0), а не за месяц до них. Это *coincident*
индикаторы — они отражают неопределённость в момент её реализации,
а не заблаговременно предсказывают решения.

### 5.2 Последние значения (март 2026)

- **Ключевая ставка:** 15.0% (−6 п.п. от пика 21%)
- **Все три MPU-индекса:** снижаются от пиков 2024 года
- **Срочная структура:** нормальная (1M IQR < 1Y IQR)

Сигнал рынка: неопределённость снижается, но ещё выше уровней
2019–2020. Рынок видит продолжение смягчения, но неуверен в темпах.

### 5.3 Рекомендации по ДКП

**1. Продолжение плавного цикла снижения ставки**

MPU_decay снижается → прогнозирует снижение RV ставки на h=3–6M
(R²_oos = +0.328 и +0.364). Это поддерживает стратегию шагов по
100–150 б.п., а не экстренных решений. Плавное снижение само по себе
сократит MPU_rv_std и создаст самоподдерживающийся тренд снижения
неопределённости.

**2. Инфляционный канал требует мониторинга**

Текущее снижение MPU_decay предсказывает (R²_oos=0.610 на h=3M)
стабилизацию инфляции в ближайшие 3 месяца. Однако исторически,
когда MPU_decay снижался резко (после пиков), инфляция запаздывала
на реагирование. Рекомендуется сохранять умеренно жёсткую ДКП до
устойчивого подтверждения снижения инфляции.

**3. Усиление forward guidance**

Событийный анализ показал: индексы реагируют на решения ЦБ
одновременно (t=0), а не заблаговременно. Это означает, что рынок
не получает достаточно информации до заседаний. Более чёткое
указание на диапазон возможных решений («при инфляции ниже X%
следующий шаг составит Y б.п.») снизит ATM IV и MPU_atm
заблаговременно.

**4. Мониторинг инверсии срочной структуры**

Тест показал значимость наклона IQR (1M−1Y) для предсказания
изменений ставки на 12M (p=0.042). Если краткосрочный MPU
начнёт превышать долгосрочный — это ранний сигнал о том, что рынок
ожидает неожиданного разворота ДКП в перспективе года.

## Приложение: Методологические ограничения

| Ограничение | Влияние | Решение |
|---|---|---|
| Малая выборка (N≈77–85 дат) | Низкая мощность тестов | Нужны данные 10+ лет |
| Структурный разрыв 2022 | Доминирует в rolling OOS | Фиксированный split IS/OOS |
| Ежемесячная частота | ΔIQR зашумлён | Недельные данные улучшат MPU_ext |
| Параметр λ Esscher | VRP нестабилен | Эконометрическая оценка λ |
| Тонкий рынок опционов | Малое число страйков в 2019–2020 | — |
