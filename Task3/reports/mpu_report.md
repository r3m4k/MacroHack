# Отчёт по индексам неопределённости денежно-кредитной политики (MPU)

**Кейс 2 — Индекс неопределённости ДКП на основе поверхности вменённой волатильности**

---

## Методология оценки

Все индексы тестируются единым методом: **out-of-sample тест (OOS)**.

**Критерий:**
$$R^2_{oos} = 1 - \frac{MSE_{model}}{MSE_{benchmark}}$$

где бенчмарк — наивный прогноз (среднее RV по in-sample периоду).

- $R^2_{oos} > 0$ — индекс лучше наивного прогноза ✅  
- $R^2_{oos} < 0$ — индекс хуже наивного прогноза ✗

**Целевая переменная:** реализованная волатильность ключевой ставки ЦБ РФ:
$$RV_t = \text{std}(\Delta r_{t-2},\ \Delta r_{t-1},\ \Delta r_t), \quad \Delta r_t = r_t - r_{t-1}$$

**Разбивка выборки:** 60% in-sample (2019–2023), 40% out-of-sample (2024–2026).  
**Горизонты прогноза:** h = 1, 2, 3, 6 месяцев.

## 1. MPU_pca

### Идея
Рынок опционов формирует распределение вероятностей будущей ставки (RND). Ширина этого распределения — квантильный коридор IQR = Q90 − Q10 — прямая мера неопределённости. Агрегация по нескольким срокам через PCA позволяет извлечь общий системный фактор неопределённости.

### Метод построения
1. Из поверхности IV извлекается RND методом Breeden-Litzenberger (1978) для каждой даты и срока (1M, 3M, 6M, 1Y).
2. Форвард F = ATM-point улыбки (страйк с минимальной IV). Ценообразование — модель Башелье.
3. Из RND вычисляется IQR_9010 = Q90 − Q10.
4. Pivot-таблица: строки = даты, столбцы = сроки. Первая главная компонента (PCA) → MPU_pca.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_pca(t) + \varepsilon$, горизонты h = 1, 2, 3, 6 месяцев.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | -2.367 ✗ |
| 2M | +0.224 ✅ |
| 3M | +0.253 ✅ |
| 6M | +0.137 ✅ |

Среднее R²_oos (h=2,3,6) = **+0.205**. PC1 объясняет 85.6% дисперсии IQR по срокам.

### Интерпретация
MPU_pca устойчиво превосходит наивный прогноз на горизонтах 2–6 месяцев. Провал на h=1M объясняется переобучением: месячный сигнал зашумлён. Высокая доля объяснённой дисперсии PC1 (85.6%) подтверждает, что сроки движутся синхронно — существует единый системный фактор неопределённости ДКП.

## 2. MPU_decay

### Идея
Аналогична MPU_pca, но агрегация по срокам — через взвешенное среднее с экспоненциальным убыванием весов. Краткосрочные сроки (1M, 3M) более чувствительны к ближайшим решениям ЦБ и несут более оперативный сигнал, чем долгосрочные (1Y+), которые включают структурные премии за риск.

### Метод построения
1. Шаги 1–3 аналогичны MPU_pca.
2. Веса сроков: $w_i = \exp(-\lambda \cdot i) / \sum_j \exp(-\lambda \cdot j)$, где $\lambda = \ln 2$.
3. Итоговый индекс: $MPU\_decay_t = \sum_i w_i \cdot IQR_{9010}(t, \text{mat}_i)$.

Веса: 1M → 0.533, 3M → 0.267, 6M → 0.133, 1Y → 0.067.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_decay(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | -1.782 ✗ |
| 2M | +0.151 ✅ |
| 3M | +0.328 ✅ |
| 6M | +0.364 ✅ |

Среднее R²_oos (h=2,3,6) = **+0.281** — лучший результат среди рыночных индексов. Корреляция с MPU_pca = 0.994.

### Интерпретация
MPU_decay — лучший индекс для среднесрочного прогнозирования. Простая взвешенная схема оказалась эффективнее PCA, что соответствует принципу parsimony в прогнозировании. Растущий R²_oos с горизонтом (0.15 → 0.36) говорит об опережающем характере индекса: он лучше работает на более длинных горизонтах, что соответствует его экономическому смыслу.

## 3. MPU_ext

### Идея
Неопределённость имеет три измерения: текущий уровень (насколько широк коридор), динамика (нарастает или спадает), хвостовой риск (вероятность экстремального сценария). Совместная агрегация трёх компонент через PCA должна давать более полную картину, чем один IQR.

### Метод построения
1. Из RND для срока 3M вычисляются три компоненты:
   - C1 = IQR_9010 (уровень)
   - C2 = Δ(IQR_9010) (ежемесячное изменение)
   - C3 = Tail_total = (Q99−Q90) + (Q10−Q01) (хвостовой риск)
2. PCA по стандартизированным C1, C2, C3 → первая компонента = MPU_ext.

PC1 объясняет 68.5%, PC2 — 29.3%, PC3 — 2.2%.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_ext(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | -6.698 ✗ |
| 2M | -0.723 ✗ |
| 3M | -0.155 ✗ |
| 6M | +0.473 ✅ |

Среднее R²_oos (h=2,3,6) = **-0.135**.

### Интерпретация
MPU_ext разочаровывает на коротких горизонтах, но показывает сильный результат на h=6M (+0.473). Проблема в компоненте C2 (Δ IQR): при ежемесячной частоте данных изменение IQR зашумлено и вносит деструктивный вклад в короткосрочный прогноз. На длинном горизонте шум сглаживается, и хвостовая компонента начинает работать. Вывод: расширение индекса динамической компонентой требует более высокой частоты данных.

## 4. MPU_rwd

### Идея
RND включает премию за риск — инвесторы платят за страховку сверх объективных вероятностей. RWD («реальное» распределение) очищено от этой премии и ближе к истинным вероятностям исходов по ставке. Неопределённость по RWD — более фундаментальная мера, чем по RND.

### Метод построения
1. Из RND каждой даты/срока строится RWD через Esscher transform:
$$q_{rw}(x) = \frac{q_{rn}(x) \cdot e^{\lambda x}}{\int q_{rn}(x) \cdot e^{\lambda x} dx}, \quad \lambda = -0.1$$
2. Из RWD вычисляется IQR_rwd = Q90_rwd − Q10_rwd.
3. PCA по IQR_rwd нескольких сроков → MPU_rwd.
4. Параллельно строится MPU_vrp = PCA по VRP = Var(RND) − Var(RWD).

PC1 для MPU_rwd объясняет 84.7%, для MPU_vrp — 67.0%.

### Метод тестирования
OOS регрессия для MPU_rwd и MPU_vrp раздельно.

### Результаты тестирования
**MPU_rwd:**

| h | R²_oos |
|---|---|
| 1M | -2.993 ✗ |
| 2M | +0.202 ✅ |
| 3M | +0.177 ✅ |
| 6M | +0.101 ✅ |

Среднее (h=2,3,6) = **+0.160**.

**MPU_vrp:**

| h | R²_oos |
|---|---|
| 1M | -0.110 ✗ |
| 2M | -4.008 ✗ |
| 3M | -3.571 ✗ |
| 6M | -7.053 ✗ |

Среднее (h=2,3,6) = **-4.877**.

### Интерпретация
MPU_rwd работает, но слабее MPU_pca. Esscher-поправка с λ = −0.1 незначительно меняет форму распределения на российском рынке — что указывает на малую и нестабильную премию за риск. MPU_vrp — катастрофический провал: разность дисперсий RND и RWD крайне нестабильна при малой выборке и неверно оцененном λ, что делает VRP ненадёжным индикатором.

## 5. MPU_atm

### Идея
Зачем восстанавливать всё распределение (RND), если мера неопределённости уже содержится в ATM-волатильности? ATM IV — прямая рыночная цена неопределённости на данном горизонте, без модельных допущений о форме улыбки.

### Метод построения
1. Для каждой даты и срока экспирации (1M, 3M, 6M, 1Y) берётся IV при страйке, ближайшем к ATM-форварду (минимум улыбки).
2. PCA по ATM IV нескольких сроков → MPU_atm.

PC1 объясняет 88.3% — самая высокая среди всех индексов IV Surface.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_atm(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | -0.994 ✗ |
| 2M | -0.112 ✗ |
| 3M | +0.271 ✅ |
| 6M | **+0.491** ✅ |

Среднее R²_oos (h=2,3,6) = **+0.217** — второе место.

### Интерпретация
MPU_atm — лучший индекс на горизонте h=6M и лучший среди методов, не требующих восстановления RND. R²_oos = 0.491 на 6-месячном горизонте — впечатляющий результат. Это подтверждает, что для долгосрочного прогнозирования RND избыточен: ATM IV содержит достаточно информации. Слабость на h=1,2M объясняется тем, что ATM IV — долгосрочный индикатор настроений рынка, медленно реагирующий на краткосрочные шоки.

## 6. MPU_rr (Risk Reversal)

### Идея
Наклон улыбки волатильности отражает асимметрию рисков: рынок дороже оценивает страховку от роста ставки (правый хвост) или от её снижения (левый хвост). Risk Reversal = IV(правое крыло) − IV(левое крыло) должен отражать направленную неопределённость.

### Метод построения
1. Для каждой даты и срока интерполируется улыбка IV.
2. Вычисляются IV в точках K_left = F − 0.25·(F−K_min) и K_right = F + 0.25·(K_max−F).
3. RR = IV(K_right) − IV(K_left).
4. PCA по RR нескольких сроков → MPU_rr.

PC1 объясняет 76.8%.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_rr(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | +0.027 ✅ |
| 2M | -3.876 ✗ |
| 3M | -5.539 ✗ |
| 6M | -7.801 ✗ |

Среднее R²_oos (h=2,3,6) = **-5.739** — худший результат.

### Интерпретация
MPU_rr — провальный предиктор RV. Причина принципиальная: Risk Reversal измеряет **направление** риска (вверх или вниз), а не **амплитуду** неопределённости. Реализованная волатильность симметрична по знаку — она растёт и при резком росте, и при резком падении ставки. RR не содержит информации об этом и к использованию в качестве MPU не рекомендуется.

## 7. MPU_bf (Butterfly)

### Идея
Кривизна улыбки IV (Butterfly) измеряет толщину хвостов относительно ATM: BF = 0.5·(IV_left + IV_right) − ATM_IV. Чем выше BF, тем дороже страховка от экстремальных сценариев по ставке.

### Метод построения
1. Аналогично MPU_rr, но BF = 0.5·(IV_left + IV_right) − ATM_IV.
2. PCA по BF нескольких сроков → MPU_bf.

PC1 объясняет 70.0%.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_bf(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | +0.077 ✅ |
| 2M | -0.808 ✗ |
| 3M | -1.126 ✗ |
| 6M | -1.966 ✗ |

Среднее R²_oos (h=2,3,6) = **-1.300**.

### Интерпретация
MPU_bf лучше MPU_rr, но всё равно не работает на горизонтах 2–6 месяцев. Хвостовая асимметрия улыбки IV на российском рынке нестабильна и слабо связана с последующей реализованной волатильностью. Возможно, BF несёт информацию о редких событиях (кризисах), но при малой выборке (85 дат) эта информация не идентифицируется статистически.

## 8. MPU_rv_std

### Идея
Простейший бенчмарк: реализованная волатильность за последние 3 месяца как прокси текущего уровня неопределённости. Основан на инерции RV — высокая волатильность сегодня предсказывает высокую волатильность завтра.

### Метод построения
$$MPU\_rv\_std_t = \text{std}(\Delta r_{t-2},\ \Delta r_{t-1},\ \Delta r_t)$$

Нормировка z-score. Данные: только ключевая ставка ЦБ РФ (не рыночные данные).

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_rv\_std(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | **+0.758** ✅ |
| 2M | **+0.491** ✅ |
| 3M | +0.197 ✅ |
| 6M | -0.144 ✗ |

Среднее R²_oos (h=2,3,6) = **+0.181**.

### Интерпретация
MPU_rv_std — лучший предиктор на коротком горизонте (h=1,2M), но это **не рыночный индекс неопределённости**, а статистический бенчмарк. Высокий R²_oos на h=1M (0.758) отражает автокорреляцию RV, а не прогнозную силу в экономическом смысле. На h=6M уходит в минус (mean-reversion): периоды высокой волатильности сменяются периодами низкой. MPU_rv_std используется как нижняя граница для оценки рыночных индексов.

## 9. MPU_rv_har

### Идея
HAR-RV (Heterogeneous Autoregressive, Corsi 2009) — стандарт литературы по реализованной волатильности. Модель разбивает RV на три компоненты с разными горизонтами памяти: дневную, недельную, месячную. Fitted values HAR-модели — ожидаемая RV, основанная на исторической структуре волатильности.

### Метод построения
$$RV_{t+1} = \alpha + \beta_d \cdot RV_{t} + \beta_w \cdot \overline{RV}^{3M}_{t} + \beta_m \cdot \overline{RV}^{6M}_{t} + \varepsilon$$

Оценённые параметры: $\beta_d=0.041$, $\beta_w=0.503$, $\beta_m=-0.477$, R²=0.046.  
Fitted values из этой регрессии → MPU_rv_har.

### Метод тестирования
OOS регрессия: $RV(t+h) = \alpha + \beta \cdot MPU\_rv\_har(t) + \varepsilon$.

### Результаты тестирования
| h | R²_oos |
|---|---|
| 1M | +0.496 ✅ |
| 2M | +0.265 ✅ |
| 3M | +0.099 ✅ |
| 6M | +0.008 ✅ |

Среднее R²_oos (h=2,3,6) = **+0.124**.

### Интерпретация
MPU_rv_har работает на всех горизонтах, включая h=6M — в отличие от MPU_rv_std. Отрицательный $\beta_m$ (mean-reversion на 6-месячном горизонте) корректно захватывается моделью. Низкий in-sample R²=0.046 объясняется дискретной природой ключевой ставки ЦБ РФ — она меняется ступенями, а не непрерывно. Как бенчмарк MPU_rv_har информативнее MPU_rv_std на длинных горизонтах.

## Итоговые рекомендации

### Для мониторинга ДКП

| Цель | Рекомендуемый индекс | Обоснование |
|---|---|---|
| Среднесрочный мониторинг (3–6M) | **MPU_decay** | Лучший R²_oos, интерпретируем |
| Долгосрочный сигнал (6M+) | **MPU_atm** | R²_oos=0.491, не требует RND |
| Краткосрочная сигнализация (1–2M) | **MPU_rv_std** | Лучший на коротком горизонте |

### Не рекомендуются

- **MPU_rr** и **MPU_vrp** — систематически хуже бенчмарка на всех горизонтах.
- **MPU_bf** — нестабилен, отрицательный R²_oos на основных горизонтах.

### Ключевой методологический вывод

> **Нужно ли вообще считать RND?**  
> Для долгосрочного прогнозирования — нет: MPU_atm (без RND) превосходит MPU_pca и MPU_rwd на h=6M.  
> Для среднесрочного — да: MPU_decay (через RND) лучший на h=3M.  
> Оптимальная стратегия: использовать оба индекса как взаимодополняющие.
